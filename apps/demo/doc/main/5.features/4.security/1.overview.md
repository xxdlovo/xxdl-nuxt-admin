## 能力范围

| 能力 | 说明 |
| --- | --- |
| 图形验证码 | 登录页 SVG 验证码，服务端 HMAC 校验，防止脚本直接撞库 |
| 登录失败锁定 | 连续密码错误达到阈值后锁定账号，可配置次数与时长 |
| 在线会话 | 登录写入 `sys_user_session`，记录 IP、浏览器、操作系统与最后活跃时间 |
| 在线用户页 | `/system/online` 查看当前会话，支持单个/批量强制下线 |
| 强制下线 | 写入 `revoked_at`，下一次请求立即失效，而不是删除用户 |
| 被踢提示 | 被强制下线的用户跳转登录页时收到警告，而不是普通“请先登录” |
| 用户解锁 | 管理员可手动清除登录失败次数与锁定时间 |

## 图形验证码

登录页从 `GET /api/captcha` 获取 SVG，登录时把用户输入放进 `captchaCode`。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `system_captcha_enabled` | `true` | 是否开启登录验证码 |

实现位置：

- `server/utils/captcha.ts`：生成 SVG、写入 HMAC Cookie、校验；
- `server/api/captcha.get.ts`：验证码接口；
- `app/pages/login.vue`：验证码展示与刷新；
- `shared/system/auth/...`：登录入参中的 `captchaCode`。

验证码 Cookie 只保存签名后的答案，不保存明文；校验失败按普通登录失败处理。

## 登录失败锁定

相关字段：

| 字段 | 说明 |
| --- | --- |
| `sys_user.login_fail_count` | 连续登录失败次数 |
| `sys_user.locked_until` | 锁定截止时间，为空表示未锁定 |

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `system_login_max_retry` | `5` | 连续失败达到该次数后锁定 |
| `system_login_lock_minutes` | `10` | 锁定时长（分钟） |

登录成功、管理员重置密码、管理员点击「解锁」都会清除失败次数与锁定时间。

权限码：`system:user:unlock`。

相关错误：

- `auth.invalidCredentials`：账号或密码错误；
- `auth.accountLocked`：账号已锁定，提示剩余分钟数。

## 在线会话

会话表 `sys_user_session`：

| 字段 | 说明 |
| --- | --- |
| `id` | 会话 ID，同时写入 `nuxt-auth-utils` session |
| `user_id` / `username` | 用户标识 |
| `ip` / `user_agent` / `browser` / `os` | 登录环境 |
| `login_at` / `last_seen_at` | 登录时间与最后活跃时间 |
| `expires_at` | 过期时间 |
| `revoked_at` / `revoked_by` | 强制下线时间与操作人 |

请求进入 tRPC 时，`sessionGuard` 会检查会话是否被撤销或过期：

- 已撤销 → `auth.sessionKicked`；
- 已过期 → `auth.sessionExpired`；
- 会话不存在/非法 → `auth.unauthorized`。

用户被停用、删除，或管理员重置密码时，会撤销该用户的全部会话。

## 在线用户与强制下线

| 项 | 说明 |
| --- | --- |
| 页面 | `/system/online` |
| 查询权限 | `system:online:list` |
| 强制下线权限 | `system:online:forceLogout` |
| 接口 | `sysOnline.page`、`sysOnline.forceLogout`、`sysOnline.batchForceLogout` |

操作语义是「踢出用户」，不是删除用户：

- 只把当前会话标记为 `revoked_at`；
- 用户记录、角色、数据都保留；
- 用户下次登录仍可正常进入。

被踢出的用户下一次请求会收到 401，前端按 `reason=kicked` 跳转：

```text
/login?reason=kicked&redirect=<原路径>
```

登录页展示“你已被管理员强制下线”的警告 Toast，而不是静默回到登录页。
