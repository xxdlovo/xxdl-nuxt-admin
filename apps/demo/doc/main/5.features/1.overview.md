`5.features/` 收敛的是「横切能力」——它们不属于某个业务模块，但几乎每个模块都要用。按需跳转，不必通读。

## 一、专题清单

| 专题 | 解决什么问题 | 入口 |
|---|---|---|
| 错误处理 | 服务端业务错误、原生端点错误、前端提示与表单校验、错误码对照 | [错误体系总览](/docs/main/features/error-handling/overview) |
| 文件与存储 | OSS 上传、上传接口契约、Nitro 桶与只读资源、存储管理页 | [文件能力总览](/docs/main/features/files/overview) |
| 缓存 | 通用缓存 API、字典缓存、RBAC 三层缓存、key 约定与新增步骤 | [缓存设计与边界](/docs/main/features/cache/overview) |
| 认证与安全 | 登录会话、密码策略、验证码、安全加固要点 | [认证与安全](/docs/main/features/security/overview) |
| 系统监控 | 运行时指标、健康检查与监控面板 | [系统监控](/docs/main/features/monitoring/overview) |
| 工程加固 | 防重放、限流、XSS 过滤等默认防线 | [防重、限流与 XSS](/docs/main/features/hardening/overview) |
| 组织架构 | 岗位、数据权限、Excel 导入导出 | [岗位、数据权限与 Excel](/docs/main/features/organization/overview) |

## 二、按场景选读

- **写业务接口**：先看错误处理（`AppError` 与 4xx 映射），再看缓存（哪些数据该缓存、怎么失效）。
- **做文件相关功能**：看文件与存储；只想上传一张图，直接看上传接口契约那页。
- **上线前自查**：安全 → 加固 → 监控 依次过一遍。
- **组织/权限相关**：组织架构专题 + [权限模型](/docs/main/reference/rbac)。
