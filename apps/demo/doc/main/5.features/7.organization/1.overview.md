## 岗位管理

| 项 | 说明 |
| --- | --- |
| 表 | `sys_post` |
| 用户关联 | `sys_user_post` |
| 页面 | `/system/post` |
| 权限 | `system:post:list` / `add` / `edit` / `del` |
| 用户表单 | 支持多选岗位，保存时同步 `sys_user_post` |

用户列表与详情会返回 `postIds` / `postNames`，导出用户时也会带岗位列。

## 自定义数据权限

角色数据范围 `data_scope = 2` 现在真正生效，关联表为 `sys_role_dept`。

| 取值 | 含义 | 实现 |
| --- | --- | --- |
| `1` | 全部数据 | 不限制 |
| `2` | 自定义部门 | 读取 `sys_role_dept`，按部门 ID 过滤 |
| `3` | 本部门 | 当前用户部门 |
| `4` | 本部门及以下 | 按部门 `path` 前缀 |
| `5` | 仅本人 | 按创建人过滤 |
| `6` | 本部门及以下 + 本人 | 部门范围与本人取并集 |

角色数据范围弹窗：`app/pages/system/role/components/RoleDataScopeModal.vue`。

- 选择“自定义部门”后展示部门多选；
- 保存时同步 `sys_role_dept`；
- 软删除的关联再次勾选时会恢复，而不是插入重复行。

解析位置：`server/drizzle/queries/buildScope.ts` 的 `listCustomDeptIds`。

## 角色分配用户

角色页新增「分配用户」弹窗：

- 页面：`app/pages/system/role/components/RoleUserAssignModal.vue`；
- 支持按用户名/昵称搜索；
- 保存时差量更新 `sys_user_role`；
- 新增/恢复/软删除都复用现有关系表；
- 变更后失效对应 RBAC 缓存。

## Excel 导入导出

统一入口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/system/excel/export` | 按 `module` 导出 xlsx |
| POST | `/api/system/excel/import` | 用户导入（当前仅支持 user） |
| GET | `/api/system/excel/template` | 下载导入模板 |

支持的导出模块：

| module | 权限 |
| --- | --- |
| `user` | `system:user:list` |
| `role` | `system:role:list` |
| `post` | `system:post:list` |
| `systemLog` | `system:systemLog:list` |
| `loginLog` | `system:loginLog:list` |
| `jobLog` | `system:jobLog:list` |

实现：

- 服务端：`server/utils/excel.ts`、`server/api/system/excel/*`；
- 前端：`app/utils/excel.ts` 的 `downloadExcel` / `importExcel`；
- 导入使用 ExcelJS，公式注入字符会转义；
- 导出上限 10,000 行。
