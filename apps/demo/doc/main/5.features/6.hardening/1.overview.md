## 防重复提交

同一个用户（未登录时按 IP）在 5 秒内，对同一个接口提交完全相同的入参，只允许第一次通过。

```ts
const addProc = proc({
  permission: 'system:user:add',
  repeatSubmit: true
})
```

- 实现：`server/trpc/middlewares/rateLimit.ts` 的 `repeatSubmitMiddleware`；
- key：用户/IP + tRPC path + 稳定序列化后的入参；
- 命中重复：抛出 `system.repeatSubmit`，HTTP 429；
- 窗口：5 秒；
- 已应用：用户、公告、岗位、任务新增/修改，代码生成导入表。

## 接口限流

固定窗口计数，超过上限返回 `system.rateLimited`（HTTP 429）。

```ts
const loginProcedure = publicProcedure.use(rateLimitMiddleware({
  limit: 10,
  windowMs: 60_000,
  scope: 'login'
}))
```

| 场景 | 限额 |
| --- | --- |
| 登录 | 每 IP 10 次/分钟 |
| 手动执行任务 | 每用户 9 次/分钟 |

限流不默认启用，只在高风险接口上显式声明。

### 边界

- 计数保存在 Node 进程内，多实例部署各自计数；
- 不引入 Redis，不保证跨实例强一致；
- 重启后计数清零；
- 不做全局限流，避免正常高频查询被误伤。

## 公告 XSS 过滤

公告富文本使用 `sanitize-html` 清洗，保存与读取两侧都会执行。

实现：`server/utils/sanitizeHtml.ts`。

| 规则 | 说明 |
| --- | --- |
| 允许标签 | `p`、`br`、`strong`、`em`、`ul/ol/li`、`a`、`img`、`h1-h6`、`blockquote`、`code`、`pre`、表格等 |
| 允许属性 | `a[href,target,rel]`、`img[src,alt,width,height]`、`class` |
| 协议 | `http`、`https`、`mailto`；图片只允许 http/https |
| 移除 | `script`、`style`、`iframe`、`on*` 事件、`javascript:` 链接 |

`SysNoticeService` 在 `create` / `updateById` 清洗写入，在 `getById` / `getOne` / `page` / `list` / `latest` 清洗返回，兼容历史脏数据。

## 菜单外链与路由参数

`sys_menu` 新增：

| 字段 | 说明 |
| --- | --- |
| `external_link` | 外链地址；设置后优先于 `path`，点击新窗口打开 |
| `query` | 路由查询参数，不带 `?`，例如 `tab=1&from=menu` |

菜单表单已增加对应输入项。导航转换在 `app/utils/navigation.ts`：

- 外链：`to = externalLink`、`target = _blank`、`external = true`；
- 普通菜单：`to = path + '?' + query`。
