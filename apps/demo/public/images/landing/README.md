# Landing screenshots

Add the following real NuxtAdmin screenshots to this directory:

- `dashboard.png`
- `users.png`
- `roles.png`
- `menus.png`

Use the same viewport and a 16:10 aspect ratio for consistent presentation.
Until an image exists, the landing page displays a neutral preview placeholder.

Contact QR codes:

- `contact/wechat.png`
- `contact/qq.png`

Square PNG images are recommended. Missing QR images display a neutral placeholder.
