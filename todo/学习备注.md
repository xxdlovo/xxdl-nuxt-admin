partial 返回的是所有字段 string  | undefined  

试用pick后, 会继承nullish的null, 所以partial会出问题 
解决方式是
```ts // 定义一个工具类型，去除 null
type NonNull<T> = {
    [K in keyof T]: Exclude<T[K], null>
}
```
