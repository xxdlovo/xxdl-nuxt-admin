本项目的模块代码高度模板化：数据库表建好后，一整套「Schema → 共享类型 → Repo → Service → Router → 页面 → 搜索 → 弹窗 → 翻译 → 权限」的代码可以连续生成出来。

生成时**参照现有模板**：`server/demo-router/` + `app/pages/demo/` 是最小闭环，`server/sys-router/user/` + `app/pages/system/user/` 是完整模块。技术栈为 Nuxt 4 + Nuxt UI 4 + tRPC + Drizzle ORM + MySQL，前后端一体。

本分组就是生成模块代码的**唯一依据**：

- [后端步骤](/docs/main/new-module/backend-steps)：Step 1 ～ 9.1，从建表到路由注册与权限配置。
- [前端步骤](/docs/main/new-module/frontend-steps)：Step 10 ～ 14，页面、搜索、弹窗、翻译与常量。
- [文件清单与注意事项](/docs/main/new-module/checklist)：命名逐级对照、19 项文件清单、坑位清单与自检项。

## 一、怎么用

数据库表建好后，向 AI 说出这句话：

```text
我已建好 <表名> 表，模块名 <module>，业务名 <business>，请根据 doc/main/4.new-module/ 帮我生成代码。
```

| 参数 | 说明 | 示例 |
| --- | --- | --- |
| `<表名>` | 数据库表名（snake_case） | `my_business` |
| `<module>` | 模块目录名，支持两级（用 `/` 分隔） | `demo` 或 `system/user` |
| `<business>` | 业务名，用于文件名与 Schema 命名（大驼峰） | `Demo` 或 `SysUser` |

示例：

```text
我已建好 demo 表，模块名 demo，业务名 Demo，请根据 doc/main/4.new-module/ 帮我生成代码。
```

```text
我已建好 sys_user 表，模块名 system/user，业务名 SysUser，请根据 doc/main/4.new-module/ 帮我生成代码。
```

```text
我已建好 sys_department 表，模块名 system/department，业务名 SysDept，请根据 doc/main/4.new-module/ 帮我生成代码。
```

> 生成前 AI 需要先向用户确认模块名（单级如 `demo`，两级如 `system/user`），确认后再按顺序执行后端与前端步骤。所有文件名、tRPC 路由名、i18n key 与页面目录都由该模块名派生，不要各自另起名字（对照表见[文件清单与注意事项](/docs/main/new-module/checklist)）。

## 二、权限资源码规则

生成 Router 之前必须先确定资源码，它同时被接口鉴权与前端按钮权限使用：

| 操作 | 权限码 |
| --- | --- |
| 列表 / 详情 / 查询 | `<resource>:list` |
| 新增 | `<resource>:add` |
| 修改 | `<resource>:edit` |
| 删除 / 批量删除 | `<resource>:del` |

资源码的换算规则：**模块名把 `/` 换成 `:`**。

- 单级模块 `demo` → 资源码 `demo`
- 两级模块 `system/user` → 资源码 `system:user`

> 生成模块时必须同步给出 `sys_menu` 的菜单与按钮权限数据，否则普通用户即使分配了角色也访问不到接口。详情见 [后端步骤](/docs/main/new-module/backend-steps)。

## 三、14 步全景

| 步骤 | 内容 | 产物 |
| --- | --- | --- |
| Step 1 | 数据库建表（人工执行 SQL） | 表 |
| Step 2 | `pnpm db:pull` 生成 Drizzle Schema | `server/drizzle/out/schema.ts` |
| Step 3 | 对比发现新表并确认 | — |
| Step 4 | Schema 导出到 `schema/index.ts` | `server/drizzle/schema/**` |
| Step 5 | 共享类型（common / input / output / index 四个文件） | `shared/<module>/**` |
| Step 6 | 后端 Repo（`CommonRepo` 工厂） | `<Business>Repo.ts` |
| Step 7 | 后端 Service（业务逻辑与抛错） | `<Business>Service.ts` |
| Step 8 | 后端 Router（显式 `proc({ permission })`） | `index.ts` |
| Step 8.1 | 核对操作类型与 `proc()` 参数 | — |
| Step 9 | 注册到 `appRouter` | `server/trpc/routers.ts` |
| Step 9.1 | 配置 RBAC 菜单与按钮权限 | `sys_menu` 数据 |
| Step 10 | 前端列表页面 | `app/pages/<模块>/index.vue` |
| Step 11 | 前端搜索组件 | `components/<前缀>-search.vue` |
| Step 12 | 前端新增/编辑弹窗 | `components/<前缀>-operate.vue` |
| Step 13 | 添加翻译 key（zh + en） | `app/locales/*.json` |
| Step 14 | 业务常量配置（可选） | `shared/constants/business.ts` |
