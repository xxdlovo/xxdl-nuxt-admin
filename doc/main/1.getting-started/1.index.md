xxdl-nuxt-admin 是一套**前后端一体的全栈 Nuxt 4 后台管理系统**。前端页面、tRPC 接口、数据库访问、定时任务都运行在同一个 Nuxt 应用内，不需要再单独维护一套后端服务。

## 项目定位

它面向这些场景：

- 内部管理工具与运营后台
- 业务管理平台（需要 RBAC 权限、数据范围、操作审计）
- 需要快速搭建又要求类型安全的中后台系统

项目的核心思路是：**把后台系统里反复出现的横切关注点一次性收敛好**，包括认证会话、按钮级权限、数据权限、操作日志、国际化、字典缓存、文件上传、定时任务，以及一套可复制的「新增模块」代码生成流程。业务开发只需按既有结构填空。

## 核心功能

### 基础框架

| 能力 | 说明 |
| --- | --- |
| 全栈单体应用 | 前端页面与 Nitro 服务端 API 同仓库、同构建产物 |
| 类型安全接口 | 基于 tRPC + `trpc-nuxt`，前端调用自带类型推断 |
| 共享校验契约 | Zod Schema 放在 `shared/`，前端表单与后端 `.input()` 共用同一份定义 |
| 数据库访问 | Drizzle ORM + MySQL，Schema 由 `db:pull` 从已有表结构生成 |

### 权限与安全

| 能力 | 说明 |
| --- | --- |
| 认证会话 | 用户名/密码登录 + 服务端 session（`nuxt-auth-utils`） |
| 路由保护 | 未登录访问后台页面会被中间件拦截 |
| RBAC 权限模型 | 用户 / 角色 / 菜单 / 路由 / 数据范围 / 按钮权限六要素 |
| 按钮级权限 | 权限码形如 `system:user:resetPwd`，前后端共用同一套生成函数 |
| 数据权限 | 角色数据范围决定列表可见的数据，由 `buildScope` 叠加查询条件 |
| demo 只读保护 | 通过 `NUXT_DEMO_MODE` 开关，演示环境下变更类接口直接返回只读错误 |

### 系统模块

后台已经内置并可直接参考的模块：

- 用户管理、角色管理、菜单管理、部门管理、用户角色关系
- 字典类型 / 字典数据、系统配置
- 通知公告（含富文本编辑器）
- OSS 文件与 OSS 配置（阿里云 / AWS / 腾讯云）
- 系统操作日志、登录日志、定时任务与任务日志
- 支付渠道配置、扫码支付（[支付模块](/docs/main/payment/overview)）、支付订单与回调日志
- 第三方登录账号与配置（OAuth）
- 个人中心（资料、头像上传、修改密码）

### 界面与体验

| 能力 | 说明 |
| --- | --- |
| 组件库 | Nuxt UI 4 + Tailwind CSS 4，优先使用 `U*` 组件 |
| 仪表盘 | 统计卡片 + ECharts 柱状/折线/环形图 + 通知与动态 |
| 表格能力 | 分页、搜索、批量选择、列设置、行内操作，全部封装为 hooks 与组件 |
| 多布局模式 | 侧边栏、顶部栏、混合布局，运行时可切换 |
| 主题定制 | 明暗模式、主题色、圆角、预设，配置落到主题抽屉 |
| 国际化 | 中文 / 英文切换，前端 `$ts` 与后端服务端翻译共用词条 |
| 水印 | 可配置的后台水印 |

### 其他

- **存储管理页**：直接查看和清理 Nitro `memory` 桶与只读资源桶。
- **缓存体系**：字典缓存、RBAC 三层缓存，写操作自动失效。
- **定时任务**：Cron 表达式校验、到期派发、执行日志与手动执行。
- **支付模块**：多渠道路由的扫码支付，含渠道密钥加密、下单/查询/关闭、回调幂等与虎皮椒适配器，见 [支付模块](/docs/main/payment/overview)。
- **文档站**：即本站，源文件都在 `doc/main/` 目录。
- **代码生成流程**：见 [新建模块](/docs/main/new-module)，按 14 步生成一整套模块代码。

## 技术栈

| 分类 | 选型 |
| --- | --- |
| 应用框架 | Nuxt 4.5.2（`ssr: false`） |
| UI | Nuxt UI 4.11.1、Tailwind CSS 4、`@iconify-json/*` 图标集 |
| 状态与路由 | Pinia 4 + `pinia-plugin-persistedstate`、Vue Router 5 |
| 接口层 | tRPC 11 + `trpc-nuxt` |
| 校验 | Zod 4 |
| 数据层 | Drizzle ORM 0.45 + MySQL（`mysql2`） |
| 会话 | `nuxt-auth-utils` + `@adonisjs/hash` |
| 国际化 | `nuxt-i18n-micro` |
| 图表 | `nuxt-echarts` + `vue-echarts` |
| 文档 | `@nuxt/content` 3 + `@nuxtjs/mdc` |
| 测试 | Vitest、`@nuxt/test-utils`、`happy-dom` |

版本号以项目根目录 `package.json` 中的实际声明为准。
