## 组件定位

`app/components/base/CopyValueBadge.vue`：展示「标签 + 值」的徽标，右侧按钮一键把值复制到剪贴板。适合在表格与详情页里展示 ID、接口路径、URL 等需要复制的短文本。

结构上是两个 Nuxt UI 组件拼成的胶囊：左侧 `UBadge`（`variant="subtle"`，带图标）+ 右侧 `UButton`（`variant="soft"`、`square`、`size="xs"`，图标在 `i-lucide-copy` / `i-lucide-check` 之间切换）。

## Props

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `label` | `string` | 必填 | 徽标前缀文本，展示为「label value」 |
| `value` | `string \| number \| null` | `null` | 要展示并复制的值 |
| `color` | `BadgeColor` | `'primary'` | 同时作用于徽标与复制按钮 |
| `icon` | `string` | `'i-lucide-hash'` | 徽标左侧图标，Iconify 名称 |

`BadgeColor` 是 Nuxt UI 的语义色集合：

```ts
type BadgeColor = 'primary' | 'secondary' | 'success' | 'info' | 'warning' | 'error' | 'neutral'
```

组件没有 `emits`、没有插槽，也不支持 `v-model`，只负责展示与复制。

## 渲染规则

- **有值才渲染**：`value` 为 `null`、`undefined` 或空字符串时，`v-if` 不通过，组件不输出任何 DOM，父级不需要自己判空。
- **值会转成字符串**：展示与复制都取 `String(value)`，因此数字同样适用（`0` 属于有值）。
- **展示文本**：`{{ label }} {{ textValue }}`，徽标内文本超出容器宽度时截断（`truncate`），完整内容保留在原生 `title`（`${label} ${textValue}`）里。
- **事件隔离**：容器与复制按钮的点击都带 `.stop`，放在表格行或可点击卡片里不会触发父级行点击。源码中的 `stopEvent()` 是空函数，作用只是配合 `.stop` 修饰符。

## 复制反馈

点击右侧按钮后：

1. 调用 `copyToClipboard(textValue)`（`app/utils/clipboard.ts`）；
2. 成功 → 图标切换为 `i-lucide-check`，并弹出 `useToastSuccess($ts('common.copySuccess'))`（中文「复制成功」）；
3. 1600ms 后图标自动恢复为 `i-lucide-copy`，重复点击会重置计时器；
4. 组件卸载时清理定时器。

失败时（浏览器拒绝剪贴板写入，且回退方案也失败）**不弹任何提示**，图标也不变化，静默返回。

## 剪贴板实现：copyToClipboard

复制能力由 `app/utils/clipboard.ts` 的 `copyToClipboard(text: string): Promise<boolean>` 提供，两级策略：

| 顺序 | 手段 | 说明 |
| --- | --- | --- |
| 1 | `navigator.clipboard.writeText` | 仅在安全上下文（HTTPS / localhost / 127.0.0.1）可用 |
| 2 | `textarea` + `document.execCommand('copy')` | 非安全上下文（例如用 `http://IP:端口` 访问后台）或第 1 步被拒时回退 |

其它约定：

- 空字符串直接返回 `false`，不触碰剪贴板 API；
- 函数只负责写入并返回布尔结果，**toast 与图标反馈由调用方决定**，因此 OpenAPI 文档页与 `CopyValueBadge` 共用同一份实现；
- 回退用的 textarea 会立即从 DOM 移除，不残留节点。

## 使用示例

最小用法：

```vue
<CopyValueBadge :label="$ts('common.id')" :value="row.id" />
```

自定义颜色与图标（现有实现：复制 OpenAPI 接口路径）：

```vue
<CopyValueBadge
  :label="$ts('module.system.openapi.path')"
  :value="endpoint.path"
  icon="i-lucide-link"
  color="neutral"
/>
```

在表格列里使用（`h()` 渲染的单元格）：

```ts
import CopyValueBadge from '~/components/base/CopyValueBadge.vue'

{
  id: 'traceId',
  header: () => $ts('common.traceId'),
  cell: ({ row }) => h(CopyValueBadge, {
    label: $ts('common.traceId'),
    value: row.original.traceId,
    color: 'neutral'
  })
}
```

模板中可直接写 `<CopyValueBadge />`（Nuxt 自动导入）；脚本里引用时按项目约定显式 `import` 并带 `.vue` 后缀，或用 `resolveComponent('CopyValueBadge')`。

## 注意事项

1. 组件内部通过 `useI18n()` 的 `$ts` 读取 `common.copy`（按钮 `aria-label` / `title`）与 `common.copySuccess`（提示文案），必须在 i18n 上下文中使用——Nuxt 插件已全局注册，页面里直接用即可。
2. `color` 只接受上述 7 个语义色；省略或传 `undefined` 时回落到默认 `'primary'`。
3. 值很长时徽标会占满容器并截断，组件本身已设 `max-w-full` + `overflow-hidden`，放进宽度受限的容器（如表格单元格）时无需再包一层。
4. `label` 会原样展示并参与 `title`，不要传空字符串——展示文本中间有固定空格，空标签会留下前导空格。
5. 需要自定义成功反馈（换提示样式、加埋点等）时，直接用 `copyToClipboard` 自行实现，不要修改这个通用组件。
