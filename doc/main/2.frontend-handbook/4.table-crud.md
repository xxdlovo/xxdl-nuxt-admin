## 设计思路

后台列表页统一由「hooks 管状态 + 通用组件管外观」组成，hooks 位于 `app/composables/useTable/`，组件位于 `app/components/table/`。

```text
app/composables/useTable/
├── useTable.ts            基础查询：data / loading / error / columns
├── usePaginatedTable.ts   在 useTable 之上加分页、搜索、刷新
├── useTableOperate.ts     新增 / 编辑 / 删除 / 批量删除的状态与回调
├── useSelectionColumn.ts  多选列
├── helpers.ts             useBadgeColumn、useActionsColumn
├── types.ts               全部类型定义
└── index.ts               统一出口
```

`app/composables/useBadgeColumn.ts` 只是把 `helpers.ts` 的 `useBadgeColumn` 再导出一遍，两种导入路径等价。

## usePaginatedTable

```ts
const { data, loading, pagination, pageSizeOptions, search, refresh, getDataByPage, reloadColumns } =
  usePaginatedTable<DemoDto>({
    query: (params) => $trpc.demo.page.query(params),
    pageSizeOptions: [10, 20, 50, 100]
  })
```

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| `query` | 必填 | 接收分页与搜索参数，返回 `{ list, total, page, pageSize }` |
| `columns` | 无 | 返回列配置的函数，语言切换时会重新执行 |
| `initialPage` / `initialPageSize` | `1` / `20` | 初始分页 |
| `pageSizeOptions` | `[10, 20, 50, 100]` | 每页条数可选项 |
| `onFetched` | 无 | 数据返回后的回调 |

返回值里 `pagination` 是 `reactive({ page, pageSize, total })`，`getDataByPage(page, params)` 会先切换页码再由内部 `watch` 触发查询；页码不变时直接查询。`refresh()` 保持当前页与搜索条件重新拉取。

## useTableOperate

```ts
const {
  operateType, editingData, drawerVisible, checkedRowKeys,
  handleAdd, handleEdit, closeVisible, onDeleted, onBatchDeleted
} = useTableOperate<DemoDto>({ data, idKey: 'id', refresh })
```

- `handleAdd()` 把 `operateType` 置为 `add` 并打开弹窗；`handleEdit(id)` 置为 `edit`，并从当前页数据中深拷贝出 `editingData`。
- `onDeleted()` / `onBatchDeleted()` 会提示 `common.deleteSuccess` 并刷新列表（批量删除还会清空 `checkedRowKeys`）。
- 删除接口本身需要在页面里调用，例如 `await $trpc.demo.remove.mutate(id)`，随后再 `await onDeleted()`。

## 列配置

列是一个 `computed<TableColumn<T>[]>`，按权限与业务拼接：

```ts
const columns = computed<TableColumn<DemoDto>[]>(() => [
  ...(permissions.canDel.value ? [selectionColumn] : []),
  { id: 'index', header: () => $ts('common.index'), cell: ({ row }) => row.index + 1 },
  { accessorKey: 'field1', header: () => $ts('module.demo.field1') },
  useBadgeColumn<DemoDto>('status', 'module.demo.demoStatus', statusBadgeConfig.value, 1),
  ...(permissions.canOperate.value ? [actionColumn] : [])
])
```

- 多选列：`useSelectionColumn({ data, checkedRowKeys, checkboxComponent: resolveComponent('UCheckbox') })`，表头支持全选与半选。
- 状态徽标：`useBadgeColumn(accessorKey, headerI18nKey, configMap, defaultValue)`，`configMap` 通常来自 `useDictBadgeConfig(code)`。
- 操作列：`useActionsColumn([{ type: 'edit', onClick }, { type: 'delete', onClick }, { type: 'custom', render }])`，`delete` 类型会自动套 `Popconfirm`。
- 拖拽/折叠场景可直接手写 `cell` 渲染函数，用 `resolveComponent('UButton')` 取组件。

## 三个表格组件

### TableWithPagination

`app/components/table/TableWithPagination.vue`

- Props：`data`、`columns`、`loading`、`pagination`、`pageSizeOptions`、`ui`、`getSubRows`、`getRowId`、`expandedOptions`、`hideExpandedSlotRow`。
- 插槽：`header`（放操作栏），其余插槽透传给内部 `UTable`；`expanded` 支持 `v-model`。
- 半透明 Loading 遮罩 + 总条数 + 每页条数选择 + `UPagination`。
- 通过 `defineExpose` 暴露 `tableRef`，父组件用 `useTemplateRef('table')` 获取。

### TableHeaderOperation

`app/components/table/TableHeaderOperation.vue`

- Props：`tableRef`、`disabledDelete`、`loading`、`batchDeleteLoading`、`selectedCount`、`addPermission`、`deletePermission`、`addLabel`、`addIcon`。
- Emits：`add`、`delete`、`refresh`。
- 插槽：默认插槽会替换内置按钮组，`prefix`、`suffix` 用于补充内容。
- 新增/批量删除按钮用 `v-permission` 控制显示，批量删除走 `UPopover` 二次确认。

### TableColumnSetting

`app/components/table/TableColumnSetting.vue`

- Props：`tableRef`（需要能拿到 `tableApi` 的表格实例）、`label`。
- 列出所有 `getCanHide()` 为真的列，勾选即切换可见性。

> 注意：`TableHeaderOperation` 依赖表格实例，必须写成 `v-if="tableRef?.tableRef"`，否则首帧拿不到实例。

## 搜索表单范式

文件：`app/pages/<模块>/components/<模块>-search.vue`

```vue
<script setup lang="ts">
import { DemoQuerySchema, type DemoQueryDTO } from '#shared/demo'

const emit = defineEmits<{ search: [data: DemoQueryDTO] }>()
const state = defineModel<DemoQueryDTO>('model', { required: true })
const form = useTemplateRef('form')
const statusItems = useDictNumberOptions(businessDictCode.enableStatus)

const submit = async () => {
  if (await form.value?.validate({})) emit('search', state.value)
}
const reset = () => {
  form.value?.clear()
  state.value = {}
}
</script>
```

约定：

- 外层 `UCard` + `UAccordion` 实现可折叠搜索面板。
- 表单用 `UForm` + `UFormField`，字段控件优先 `UBaseInput`（自带清空按钮）与 `USelect`。
- schema 必须使用当前模块的 `QuerySchema`，`label` 与 `placeholder` 都用 `$ts()`。
- 页面侧用 `v-model:model="searchParams"` 与 `@search="getDataByPage(1, searchParams)"` 连接。

## 操作弹窗范式

文件：`app/pages/<模块>/components/<模块>-operate.vue`

```vue
<script setup lang="ts">
const { schema, validate } = useZodValidation({
  schema: () => (props.operateType === 'add' ? DemoAddSchema : DemoUpdateSchema)
})

const handleSave = async () => {
  await $trpc.demo.create.mutate(state.value)
  useToastSuccess($ts('common.addSuccess'))
}
</script>
```

约定：

- 容器用 `UModal`（`v-model:open`），由父页面通过 `v-model:visible`、`:operate-type`、`:data`、`:close`、`:refresh` 传入。
- 校验用 `useZodValidation`，把 `validate` 直接传给 `UForm` 的 `:validate`，错误消息会自动走 `$ts` 翻译。
- 打开弹窗时（`watch(visible)`）重新初始化表单，避免残留上一次的编辑值。
- 提交成功后提示并调用 `props.refresh?.()`，再关闭弹窗。

## 页面骨架

完整可运行示例见 `app/pages/demo/index.vue`，结构固定为：

```text
<div class="h-full flex flex-col p-3 gap-3">
  ├─ <模块>-search  搜索表单
  └─ UCard > TableWithPagination
       ├─ #header > TableHeaderOperation（内含 <模块>-operate 弹窗）
       └─ 分页与表格本体
```

初始化加载统一写在 `onMounted(async () => { await search() })`（`ssr: false`）。

## 常见问题

1. 表格不渲染操作栏：检查 `tableRef?.tableRef` 条件是否成立，以及是否把 `ref="table"` 绑在 `TableWithPagination` 上。
2. 删除/编辑按钮不显示：列数组里需要用 `permissions.canEdit.value` / `canOperate.value` 判断，选择列用 `canDel.value`。
3. 语言切换后表头还是旧语言：列必须写成函数式 `columns: () => [...]`，或使用 `computed`；`useTable` 内部会监听 locale 调用 `reloadColumns()`。
4. 删除后列表不刷新：`remove.mutate` 之后要显式 `await onDeleted()`。
5. 搜索后停在旧页码：搜索入口应调用 `getDataByPage(1, searchParams)`。
