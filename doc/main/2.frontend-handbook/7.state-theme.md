## 状态管理总览

`@pinia/nuxt` 提供 Pinia，`pinia-plugin-persistedstate` 负责持久化，项目自定义了 storage 适配器 `app/stores/persistedStorage.ts`：

```ts
export const localStoragePersist = {
  getItem: (key) => import.meta.client ? window.localStorage.getItem(key) : null,
  setItem: (key, value) => { if (import.meta.client) window.localStorage.setItem(key, value) }
}
```

它在服务端渲染阶段直接返回 `null`，避免 `window` 未定义。

| Store | 文件 | 职责 | 持久化 |
| --- | --- | --- | --- |
| `theme` | `app/stores/theme.ts` | 布局模式与全部外观设置 | 是（key `theme`） |
| `tabs` | `app/stores/tabs.ts` | 后台标签页 | 是（key `tabs`） |
| `rbacProfile` | `app/stores/rbacProfile.ts` | 当前用户权限档案与菜单 | 否（会话内） |
| `dict` | `app/stores/dict.ts` | 字典数据会话内缓存 | 否（会话内） |

组合式用法优先：`useThemeStore()`、`useTabsStore()`、`useRbacProfile()`、`useDictStore()`。

## theme store

设置按区域分片，默认值集中在文件顶部的常量对象里：

| 分片 | 关键字段 |
| --- | --- |
| `header` | `height`、`breadcrumbVisible`、`breadcrumbIconVisible` |
| `tab` | `visible`、`height`、`mode`（`chrome` / `button`）、`middleClickClose` |
| `sider` | `width`、`collapsedWidth`、`mixWidth`、`mixChildMenuWidth`、`autoSelectFirstMenu` |
| `footer` | `visible`、`height` |
| `content` | `scrollMode`（`wrapper` / `content`）、`pageAnimate`、`pageAnimateMode` |
| `general` | `localeVisible`、`globalSearchVisible`、`watermark.*` |

常用方法：`setLayoutMode`、`toggleSiderCollapse`、`setSiderCollapse`、`toggleMixSiderFixed`、`resetLayoutSettings`、`getLayoutSettingsSnapshot`。

持久化声明在两个地方：

1. `persist.pick` 列表（插件机制）。
2. 文件底部的 `watch` + `localStorage` 写入（key 为 `theme:layoutMode` 与 `theme:layoutSettings`），并在初始化时通过 `loadLayoutSettings()` 逐字段校验回填。

改动设置项时要同时维护这三处，否则会出现「重置不彻底」或「重启后丢失」。

## tabs store

标签页数据来自页面 `definePageMeta({ title, icon })`。

| 方法 | 用途 |
| --- | --- |
| `ensureHome(tab)` | 确保首页标签存在且不可关闭（固定 `/system/home`） |
| `upsertTab(tab)` | 打开或更新标签，并设为激活 |
| `activate(path)` | 切换激活标签 |
| `closeTab` / `closeOthers` / `closeRight` / `closeAll` | 各类关闭操作，均跳过不可关闭项 |
| `getAdjacentTab` / `getLastTab` | 关闭当前标签后决定跳转目标 |
| `refreshActive()` | 递增 `refreshKey`，布局据此重挂载内容区 |
| `isManuallyClosed` / `clearManuallyClosedPaths` | 记录被手动关闭的路径，避免被再次自动打开 |

持久化只保留 `tabs` 与 `activePath`（`pick` 列表）。

## dict store

- `loadDict(code, force?)`：按字典编码加载，同编码的并发请求会合并为一次（`pendingByCode`）。
- `clearDict(code?)`：清理单个编码或全部。
- `codeByTypeId`：`typeId → code` 的反查缓存，配合 `getCodeByTypeId`、`clearDictByTypeIds` 使用（字典类型改动后按类型清理）。
- 数据只保留在当前会话，不从 `localStorage` 恢复。

## rbacProfile store

保存 `auth.profile` 的结果，`loadProfile(force)` 默认命中缓存，`clearProfile()` 用于登出与切换账号。权限判定与菜单渲染细节见权限章节。

## 主题色与圆角

- 默认外观在 `app/app.config.ts`：`theme.radius`、`theme.blackAsPrimary`、`ui.colors`（primary/secondary/success/info/warning/error/neutral）。
- `app/composables/useThemeColors.ts` 负责读写：`getThemeColors`、`setThemeColor`、`resetThemeColors`、`initializeThemeColors`、`setBlackAsPrimary`。
- 持久化使用 `localStorage`，key 前缀为 `nuxt-ui-theme-`（兼容旧前缀 `nuxt-ui-`），徽标色另有 `nuxt-ui-black-as-primary`。
- `app/app.vue` 通过 `useHead` 注入 CSS 变量（`--ui-radius`、`--ui-primary`、主题色样式表），因此颜色变更即时生效，无需重建。

## 暗色模式

由 Nuxt UI 的 `useColorMode()` 管理，`app/layouts/docs.vue` 使用 `UColorModeButton`，后台可从主题抽屉切换。水印与部分自绘样式会根据 `colorMode.value` 选择不同的填充色。

## 布局模式

- 常量与说明：`shared/layout.ts` 的 `layoutModes`、`layoutModeRecord`、`layoutModeDetailRecord`。
- 组合式函数：`app/composables/useLayoutMode.ts` 提供 `layoutMode`、`layoutModeOptions`（含图标与描述）、`setLayoutMode`。
- 六种模式：`vertical`、`vertical-mix`、`vertical-hybrid-header-first`、`horizontal`、`top-hybrid-sidebar-first`、`top-hybrid-header-first`。
- `app/layouts/system.vue` 按当前模式选择菜单模块，小屏强制 `vertical`。

## 水印

`app/components/base/BaseWatermark.vue` 读取 `theme.general.watermark`：

- `visible` 控制是否渲染，`userNameVisible` 显示昵称或账号，`currentTimeVisible` 显示时间。
- `timeFormat` 支持 `YYYY-MM-DD HH:mm`、`YYYY/MM/DD HH:mm`、`YYYY-MM-DD HH:mm:ss`。
- 组件挂载在 `app/app.vue` 的 `ClientOnly` 中，水印文案由 SVG 生成。

## 主题抽屉

后台外观设置有统一入口：`app/layouts/modules/theme-drawer/`，下分四个模块：

- `appearance`：主题色、圆角、明暗模式。
- `general`：语言开关、全局搜索开关、水印设置。
- `layout`：布局模式与顶栏/侧栏/标签栏/页脚/内容区设置。
- `preset`：预设方案。

新增外观设置项时，需要同时更新 theme store 的默认值、`persist.pick`、`loadLayoutSettings` 与抽屉中的对应面板。
