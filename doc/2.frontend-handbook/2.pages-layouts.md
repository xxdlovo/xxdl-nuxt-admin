## 文件路由与页面组织

`app/pages` 下的文件即路由，页面按业务模块分目录组织：

```text
app/pages/
├── index.vue                    # /               落地页
├── login.vue                    # /login          登录
├── register.vue                 # /register       注册
├── system/                      # /system/**      后台模块
│   ├── home/index.vue           # /system/home
│   ├── user/index.vue           # /system/user
│   ├── user/profile.vue         # /system/user/profile
│   └── user/components/         # 该模块私有组件
├── demo/index.vue               # /demo           最简 CRUD 示例
└── docs/                        # /docs/**        文档站（Nuxt Content）
```

约定：

- 模块页面固定为 `index.vue`，私有组件放同级 `components/` 目录。
- 私有组件命名与模块同名并带后缀，例如 `demo-search.vue`、`demo-operate.vue`。
- 页面内导入私有组件必须带显式后缀：`import DemoSearch from './components/demo-search.vue'`。

## definePageMeta 用法

```ts
definePageMeta({
  layout: 'system',
  title: 'Demo示例',
  icon: 'i-lucide-sparkles'
})
```

- `layout`：后台页面写 `'system'`；文档页写 `'docs'`。
- `title` / `icon`：供标签页（`app/stores/tabs.ts`）与面包屑显示，同时也是菜单兜底文案来源。
- `pageTransition: false`：文档页需要显式关闭过渡，避免异步 `ContentRenderer` 切换时正文消失。

## 全局路由守卫

`app/middleware/auth.global.ts`：

- 公开路径：`/`、`/landing`、`/login`、`/register`，以及 `/docs` 与 `/docs/**`。
- 首次进入时如果 `loggedIn` 为假，会先 `await fetch()` 拉取一次 session。
- 未登录访问受保护路径：跳转 `/login?redirect=<完整路径>`。
- 已登录访问 `/login`：跳转 `/system/home`。

新增公开页面时，需要把路径加入该中间件的 `isPublicPath` 判断，否则会被登录拦截。

`app/middleware/layout.global.ts`：把 `/` 与 `/landing` 的布局改写为 `landing`。

## 四种布局

| 布局 | 文件 | 用途 |
| --- | --- | --- |
| `default` | `app/layouts/default.vue` | 极简上/中/下结构：顶栏 + 内容区 + 页脚 |
| `system` | `app/layouts/system.vue` | 后台主布局：菜单、顶栏、标签页、内容区 |
| `docs` | `app/layouts/docs.vue` | 文档站布局：左侧导航 + 右侧目录 + 搜索 |
| `landing` | `app/layouts/landing.vue` | 落地页布局 |

## system 布局的工作方式

`app/layouts/system.vue` 本身不画界面，而是按 `themeStore.layoutMode` 动态切换菜单模块：

```ts
const modeMap: Record<LayoutMode, Component> = {
  vertical: LayoutVertical,
  'vertical-mix': LayoutVerticalMix,
  'vertical-hybrid-header-first': LayoutVerticalHybridHeaderFirst,
  horizontal: LayoutHorizontal,
  'top-hybrid-sidebar-first': LayoutTopHybridSidebarFirst,
  'top-hybrid-header-first': LayoutTopHybridHeaderFirst
}
```

要点：

- 小屏（`max-width: 1023px`）强制使用 `vertical` 布局。
- 菜单数据来自 `useRbacProfile().profile.menus`，`onMounted` 时调用 `loadProfile()` 拉取。
- `tabsStore.refreshKey` 透传给内容区，用于“刷新当前标签页”。
- 六种布局模式常量定义在 `shared/layout.ts` 的 `layoutModes`。

## 页面过渡

`app/app.vue` 统一生成过渡配置：

- `theme.content.pageAnimate === false` 或模式为 `none` 时不过渡。
- `/docs` 与 `/docs/**` 恒为 `false`（Markdown 异步渲染与嵌套 `UPage` 的要求）。
- 其余页面使用 `{ name: pageAnimateMode, mode: 'out-in' }`。

因此文档页面模板必须保持单一根节点，且根级注释也要放在容器内部。

## 新增页面的步骤

1. 在 `app/pages/<模块>/` 下新建 `index.vue`，声明 `definePageMeta({ layout: 'system' })`。
2. 需要搜索表单与操作弹窗时，建立 `components/` 子目录并放入 `<模块>-search.vue`、`<模块>-operate.vue`。
3. 在服务端注册对应菜单并通过角色分配按钮权限（见权限章节），页面才能出现在后台菜单中。
4. 补齐 `app/locales/zh.json` 与 `app/locales/en.json` 中的文案。
