## 组件目录与导入约定

```text
app/components/
├── Popconfirm.vue          删除二次确认（UPopover 实现）
├── SplitLayout.vue         主从分栏布局
├── UserProfile.vue         用户信息
├── base/                   基础组件
│   ├── BaseSearch.vue
│   ├── BaseSwitchLocal.vue
│   ├── BaseThemePick.vue
│   └── BaseWatermark.vue
├── table/                  表格组件
│   ├── TableWithPagination.vue
│   ├── TableHeaderOperation.vue
│   └── TableColumnSetting.vue
└── u/                      Nuxt UI 的薄封装
    └── BaseInput.vue
```

`app/components`、`app/composables`、`app/utils` 都是自动导入的，模板中可以直接使用组件名。**项目约定**是：页面引用业务组件时显式写 `import` 并带 `.vue` 后缀，例如：

```ts
import DemoSearch from './components/demo-search.vue'
import TableWithPagination from '~/components/table/TableWithPagination.vue'
```

页面私有组件统一放在 `app/pages/<模块>/components/`，命名与模块同名，例如 `demo-search.vue`、`demo-operate.vue`。

## 表格组件

| 组件 | 关键 props / emits | 说明 |
| --- | --- | --- |
| `TableWithPagination` | props：`data`、`columns`、`loading`、`pagination`、`pageSizeOptions`；插槽 `header`；暴露 `tableRef` | 表格 + Loading 遮罩 + 分页栏 |
| `TableHeaderOperation` | props：`tableRef`、`disabledDelete`、`loading`、`batchDeleteLoading`、`selectedCount`、`addPermission`、`deletePermission`、`addLabel`、`addIcon`；emits：`add`、`delete`、`refresh`；插槽 `prefix`、`suffix`、默认插槽 | 新增/批量删除/刷新/列设置操作栏 |
| `TableColumnSetting` | props：`tableRef`、`label` | 列显隐下拉菜单 |

用法细节与完整骨架见表格与 CRUD 章节。

## 基础组件

### BaseInput

`app/components/u/BaseInput.vue`，包装 `UInput` 并统一处理空值：

| Prop | 可选值 | 说明 |
| --- | --- | --- |
| `type` | `text` / `password` / `email` / `number` / `tel` / `url` | 默认 `text` |
| `trailing` | `clear` / `password` / `copy` / `other` / `null` | 尾部按钮类型 |
| `clearable` | 布尔，默认 `true` | 未指定 `trailing` 时是否显示清空按钮 |

特点：`number` 类型会自动把字符串转成数字或 `null`；`trailing="password"` 提供显隐切换；`trailing="copy"` 复制到剪贴板并在 2 秒后复位；其余属性通过 `$attrs` 透传给 `UInput`。

### BaseSwitchLocal

语言切换组件，读 `i18n_locale` Cookie 并调用 `$switchLocale`，详见国际化章节。

### BaseThemePick

主题色选择入口，配合 `useThemeColors()` 读写 `app.config.ts` 中的 `theme.colors`。

### BaseWatermark

水印层，挂载在 `app/app.vue` 的 `ClientOnly` 中，受 `theme.general.watermark` 控制。

### BaseSearch

`app/components/base/BaseSearch.vue` 目前只是一个带 Tooltip 的搜索按钮占位实现（点击仅打印日志），尚未接入搜索逻辑。实际搜索界面请使用各模块自己的 `<模块>-search.vue`（`UCard` + `UAccordion` + `UForm`）。

## 通用组件

### Popconfirm

删除确认气泡，被表格操作列与批量删除复用：

| Prop | 默认 | 说明 |
| --- | --- | --- |
| `content` | `common.confirmDelete` 的翻译 | 提示文案 |
| `positiveText` | `common.delete` | 确认按钮文案 |
| `negativeText` | `common.cancel` | 取消按钮文案 |
| `loading` | `false` | 传入后等待外部完成再关闭 |

事件：`confirm`；插槽：`trigger`（触发器）。`loading` 由真变假时会自动关闭气泡。

### SplitLayout

主从分栏容器，适合「左侧列表 + 右侧详情」：

| Prop | 默认 | 说明 |
| --- | --- | --- |
| `data` | `[]` | 左侧可选项列表 |
| `pagination` | `{ page: 1, pageSize: 10, total: 0 }` | 分页配置 |
| `searchPlaceholder` | `搜索...` | 搜索框占位 |
| `showPagination` | `true` | 是否显示分页 |
| `selectionMode` | `single` | `single` / `multiple` |
| `defaultWidth` | `320` | 左侧默认宽度 |
| `collapsible` | `true` | 是否可折叠 |
| `loading` | `false` | 加载态 |
| `showDraw` | `true` | 是否显示拖拽条 |

事件：`search`（300ms 防抖）、`select`、`pageChange`、`pageSizeChange`、`widthChange`。示例页面见 `app/pages/show-case/split-layout/`。

## 图标体系

配置在 `nuxt.config.ts` 的 `icon` 字段：

```ts
icon: {
  provider: 'server',
  clientBundle: { includeCustomCollections: true },
  customCollections: [{ prefix: 'custom', dir: './app/assets/icons' }]
}
```

- 使用 Iconify 名称，常见前缀有 `i-lucide-*`、`i-tabler-*`、`i-mdi-*` 以及自有集合 `custom:*`。
- 已安装的图标集：`@iconify-json/lucide`、`@iconify-json/tabler`、`@iconify-json/simple-icons`、`@iconify-json/selfhst`。
- 菜单图标允许写 `lucide:home` 形式，`normalizeNavigationIcon` 会转换成 `i-lucide-home`。
- 页面元信息里的 `icon` 会用于标签页与面包屑。

## Nuxt UI 使用原则

1. 优先使用 `U*` 组件：`UCard`、`UTable`、`UForm`/`UFormField`、`UModal`、`UButton`、`USelect`、`URadioGroup`、`UAccordion`、`UPagination`、`UPopover`、`UDropdownMenu`、`UColorModeButton` 等。
2. 样式定制走 `ui` prop 或 Tailwind 类名，不覆盖组件内部实现。
3. 消息提示统一用 `app/utils/toast.ts` 的 `useToastSuccess` / `useToastInfo` / `useToastWarning` / `useToastError`（签名：`(title, duration?, message?)`）。
4. 表格内渲染自定义内容时用 `h()` + `resolveComponent('UButton')`，保持列工厂为纯函数。

## 新增组件的步骤

1. 通用组件放 `app/components/<分组>/`，页面私有组件放 `app/pages/<模块>/components/`。
2. 使用 `<script setup lang="ts">`，props 用 `defineProps` + `withDefaults`，事件用 `defineEmits`，双向绑定用 `defineModel`。
3. 文案一律 `$ts()`，不硬编码中文。
4. 需要暴露内部实例时用 `defineExpose`（例如表格实例）。
5. 引用方显式 `import` 并带 `.vue` 后缀。
