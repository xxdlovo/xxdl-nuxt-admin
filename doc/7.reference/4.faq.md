## 环境与启动

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 安装依赖后启动报缺少类型或虚拟模块 | 未生成 Nuxt 类型声明 | 执行 `pnpm install`（会自动跑 `nuxt prepare`），必要时再执行 `pnpm post` |
| 数据库连不上 | `.env` 未配置 | 参考 [.env.example](.env.example) 填写 `DB_HOST` / `DB_DATABASE` / `DB_USER` / `DB_PASSWORD` |
| 表结构不存在 | 未初始化数据库 | 依次导入 `doc/mysql-ddl.sql` 与 `doc/init.sql`，或使用 `pnpm db:push` |
| 没有可登录账号 | 未写入种子管理员 | 配置 `.env` 中的 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 后执行 `pnpm seed:admin` |

常用命令：

| 命令 | 用途 |
| --- | --- |
| `pnpm dev` | 启动开发服务器 |
| `pnpm build` / `pnpm preview` | 构建与本地预览产物 |
| `pnpm typecheck` | 类型检查 |
| `pnpm test` | 单元测试 |
| `pnpm db:push` / `pnpm db:pull` | 依据 schema 推送结构 / 从数据库反向生成 |
| `pnpm seed:admin` | 写入种子管理员账号 |

环境变量的完整清单见[环境准备](/docs/getting-started/installation)。

## 登录与会话

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 登录接口返回成功，但后续请求仍是未登录 | 通过 `http://IP:端口` 访问时浏览器拒收 `Secure` Cookie | 设置 `NUXT_SESSION_COOKIE_SECURE=false` 后重启 |
| 生产环境登录异常 | 生产默认要求 HTTPS（`secure = true`） | 使用 HTTPS，或显式设置 `NUXT_SESSION_COOKIE_SECURE=false` |
| 修改密码提示原密码错误 | 已设置过真实密码的账号必须校验原密码 | 传入 `oldPassword`；OAuth 建号用户使用占位密码时无需原密码 |
| 注册接口返回已关闭 | 配置项 `system_register_enable` 不是 `yes` | 在系统配置中调整，或改用管理员创建账号 |

会话密钥 `NUXT_SESSION_PASSWORD` 必须配置为足够长的随机字符串；源码中保留的默认空值只是类型占位，实际值由环境变量注入。

## 权限

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 接口返回无权限 | 角色未勾选对应权限码 | 在角色管理中分配菜单/按钮权限，写操作会主动失效缓存 |
| 改完权限页面立刻没变化 | 前端 `profile` 只加载一次，服务端还有 15 分钟 RBAC 缓存 | 重新登录，或调用 `loadProfile(true)` 强制刷新 |
| 列表查不到数据 | 数据范围过滤 | 检查角色 `data_scope` 与用户部门归属 |
| 超级管理员也被拦截 | 一般不是权限问题 | 检查是否为 demo 只读模式，或接口入参校验失败 |

原理与数据范围取值见[权限模型](/docs/reference/rbac)。

## 语言与文案

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 界面语言未按上次选择恢复 | 语言 Cookie 名称不一致 | 项目统一使用 `i18n_locale`，不要改为模块默认的 `user-locale` |
| 默认显示英文 | 默认语言为 `en`，路由策略为 `no_prefix`（地址中不带语言前缀） | 在界面切换语言，选择会写入 Cookie |
| 服务端返回的提示是英文 | 服务端按 `x-locale` → `i18n_locale` → `accept-language` 顺序判定语言 | 检查请求头与 Cookie |
| 新增的翻译不生效 | 写到了构建产物目录 | 只改 `app/locales/zh.json` 与 `app/locales/en.json`；`app/locales/pages/**` 与 `server/assets/_locales/**` 是生成产物 |

翻译 key 的组织方式与生成流程见[新增业务模块](/docs/new-module)。

## 类型检查与构建

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `TS5023 Unknown compiler option 'libReplacement'` | Nuxt 生成的 tsconfig 写入当前 TypeScript 版本不认识的选项 | 项目已在 `prepare:types` 钩子中移除该字段，确认使用仓库内版本的类型检查脚本 |
| `Package import specifier "#imports" is not defined` | `trpc-nuxt` 产物需要在 Nuxt 构建管线中解析 | 保留 `build.transpile: ['trpc-nuxt']` 配置 |
| 依赖解析报找不到 MDC | pnpm 严格依赖布局 | 项目已显式声明并注册 `@nuxtjs/mdc`，不要移除 |

## 数据与初始化

| 事项 | 说明 |
| --- | --- |
| 初始化顺序 | 先导入 `doc/mysql-ddl.sql`，再导入 `doc/init.sql` |
| 反向生成 | `pnpm db:pull` 依据数据库生成 Drizzle schema |
| 结构推送 | `pnpm db:push` 依据 schema 修改数据库结构，执行前确认影响范围 |
| 新增业务表 | 建表后按[新建模块](/docs/new-module)的[后端步骤](/docs/new-module/backend-steps)与[前端步骤](/docs/new-module/frontend-steps)生成前后端代码 |

## 文件上传与存储

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 上传 400 提示缺少文件或配置 | multipart 字段不符合约定 | 表单字段必须是 `configId` 与 `file` |
| 上传 403 | 当前用户既不是管理员，也没有 `system:oss:add` | 分配权限或使用管理员账号 |
| 上传 404/提示配置不可用 | `sys_oss_config` 中没有可用的上传配置 | 在存储配置页新增并校验配置 |
| 上传不走 tRPC | 需要 `multipart/form-data` 与进度反馈 | 直接请求 `POST /api/system/oss/upload`，用原生 `xhr` 展示进度 |
| 存储管理页删不掉某些键 | `assets` 桶只读，删除接口只接受 `memory` 桶 | 只读资源请直接改仓库文件 |

## 缓存

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 重启后缓存全没了 | 缓存是进程内 memory | 属于预期行为，缓存不承担持久化职责 |
| 多实例数据不一致 | memory 缓存不跨实例共享 | 关键数据始终以数据库为准，缓存只做读优化 |
| 改了字典/权限没立刻生效 | 写操作会失效缓存，但前端还有会话级缓存 | 刷新页面；必要时检查缓存键是否被正确清理 |

缓存键、有效期与使用约定见[字典与系统配置](/docs/reference/dict-config)。

## 定时任务

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 任务不自动执行 | `nitro.scheduledTasks` 当前被注释，自动调度默认未启用 | 取消注释并重启，详见[调度与执行](/docs/scheduled-jobs/dispatch) |
| 保存任务报 Handler 缺失 | `handler_code` 未注册 | 在 `handlers` 数组中注册后再保存 |
| 保存任务报时区不支持 | `cron_timezone` 只能是 `Asia/Shanghai` | 改为该值 |
| 表达式被拒 | 字段数、范围或步长不合法 | 参考 [Cron 表达式](/docs/scheduled-jobs/cron) |
| 任务卡在执行中不再触发 | `running_status` 残留为 `1` | 手动改回 `0` |

## 文档站

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 新增的 Markdown 没有出现在侧栏 | 缺少目录级 `.navigation.yml` 或数字前缀 | 目录内补 `title` / `icon` / `navigation: true`，文件名用 `1.xxx.md` 控制顺序 |
| 页面地址与文件名不一致 | 数字前缀与 `index` 不参与路由路径 | `doc/6.scheduled-jobs/1.overview.md` 对应 `/docs/scheduled-jobs/overview` |
| 切换文档时正文消失 | 文档页依赖异步渲染，多根节点会触发过渡异常 | 文档页面保持单根节点并沿用 `layout: docs` |
| 搜索或上下页链接跳错 | 内容路径不带 `/docs` 前缀 | 应用层统一补齐前缀，新增页面无需处理 |
| 想让 Markdown 不进导航 | 在 front-matter 中设 `navigation: false` | 页面仍可通过 URL 访问，只是不出现在侧栏 |

文档站的编写约定见[文档站使用指南](/docs/getting-started/docs-guide)，目录组织见[目录结构](/docs/getting-started/structure)。

## 演示模式

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 新增、修改、删除类操作一律失败 | `NUXT_DEMO_MODE=true` 时变更接口被只读中间件拦截，返回 `system.demoReadonly` | 关闭该环境变量后重启；这也是演示环境保护线上数据的方式 |
| 查询接口正常 | 只读保护只作用于标记为可变的接口 | 不需要处理 |
